# Sermon Timestamp Transcriber & Cutter (GPU Edition)

โปรแกรม Desktop App สำหรับถอดข้อความเสียงบทเทศน์ภาษาไทย (`.mp3`, `.m4a`, `.wav`) พร้อมระบุช่วงเวลา (Timestamp) แยกหมวดหมู่ไฮไลต์สี พรีวิวฟังเฉพาะท่อนที่เลือกต่อกัน และตัดรวมเป็นไฟล์เสียงใหม่ โดยประมวลผลผ่านการ์ดจอ NVIDIA (CUDA) แบบออฟไลน์

## ความสามารถหลัก (v12)
- **ถอดเสียงความแม่นยำสูงด้วย GPU:** ใช้โมเดล OpenAI Whisper (`large-v3`) ผ่าน `faster-whisper` และ `BatchedInferencePipeline` พร้อมโปรไฟล์สำหรับการ์ดจอ **VRAM 8GB** และ **16GB**
- **คลังคำศัพท์เฉพาะทางพระพุทธศาสนา:** เพิ่ม/แก้ไขคำศัพท์เฉพาะ (เช่น *ภุมมเทวา, อากาสเทวา, เคสสตั๊ดดี้*) เพื่อช่วยให้ AI สะกดคำได้ถูกต้องมากขึ้น
- **จัดการชนิดเนื้อเรื่องและสีไฮไลต์เองได้:** เพิ่ม เปลี่ยนชื่อ ลบ และเลือกสีไฮไลต์ได้ไม่จำกัด พร้อมบันทึกการตั้งค่าไว้ถาวรที่ `Documents\SermonTranscriberConfig`
- **คัดเลือกท่อนได้สะดวกรวดเร็ว:**
  - กด `Shift` หรือ `Ctrl` ค้างไว้เพื่อเลือกหลายท่อน
  - กด `Spacebar` เพื่อติ๊กเลือกและลงสีตามชนิดที่โฟกัสอยู่ (กดซ้ำเพื่อยกเลิก)
  - ดับเบิลคลิก หรือ คลิกขวา เพื่อติ๊กเพิ่มท่อนที่ต้องการ
  - กด `F2` เพื่อแก้ไขเวลา (Timestamp) หรือข้อความในตาราง
- **มีเดียเพลย์เยอร์พรีวิวในตัว:** กดฟังเฉพาะท่อนที่ติ๊กเลือกเรียงต่อกันก่อน Export พร้อมตัวปรับเผื่อเวลา **เริ่ม / จบ** (วินาที)
- **บันทึกและนำเข้าโปรเจกต์ (`.sermon.json`):** เปิดงานเก่ากลับมาจัดสีหรือตัดเสียงต่อได้โดยไม่ต้องถอดเสียงใหม่
- **Export ครบทั้งเสียงและข้อความ:**
  - **ไฟล์เสียง:** `.mp3`, `.m4a`, `.wav` (เลือกแบบรวม 1 ไฟล์, แยกไฟล์ย่อย หรือทั้งคู่)
  - **บทถอดความ:** `.html` (เก็บสีไฮไลต์ เปิดใน Word ได้), `.csv` (Excel), `.txt`, `.srt`

## ความต้องการของระบบ
- **OS:** Windows 10 / 11 (64-bit)
- **Python:** เวอร์ชัน 3.10 หรือ 3.11 ขึ้นไป
- **GPU:** การ์ดจอ NVIDIA ที่รองรับ CUDA (แนะนำ VRAM 8GB ขึ้นไป พร้อมไดรเวอร์เวอร์ชันล่าสุด)

## วิธีติดตั้งและใช้งาน

1. **ดาวน์โหลดหรือ Clone โปรเจกต์นี้ลงเครื่อง**
2. **ติดตั้งไลบรารีที่จำเป็นทั้งหมดในคำสั่งเดียว** (เปิด CMD หรือ Terminal ในโฟลเดอร์โปรเจกต์):
   ```bash
   pip install -r requirements.txt
   ```
3. **เปิดใช้งานโปรแกรม:**
   ```bash
   python sermon_app.py
   ```

> **หมายเหตุ:** การกดถอดเสียงครั้งแรกสุดจำเป็นต้องเชื่อมต่ออินเทอร์เน็ตเพื่อให้โปรแกรมดาวน์โหลดโมเดล `large-v3` (ขนาดประมาณ 3 GB) มาเก็บไว้ในเครื่อง หลังจากนั้นสามารถใช้งานแบบออฟไลน์ได้เต็มรูปแบบ
